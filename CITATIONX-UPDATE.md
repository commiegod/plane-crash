# Citation X private-jet update

The private-jet option now uses a free authored Cessna Citation X with original black-stripe paint, modeled cabin and cockpit, and five live flight/navigation/engine display surfaces. This replaces the procedural Gulfstream selection. The internal g650 key is retained for compatibility; visible branding, dimensions, mass, approach/takeoff speeds and the eight-passenger/two-crew layout now describe the Citation X.

The same geometry and paint are used for intact, three-section and fragmented crashes. Gear visibility follows the gear control and collapsed-gear crash state. The optimized GLB is 2.61 MB, with about 0.72 MB of textures; assets are loaded on demand. Source and conversion scripts accompany the GPLv2 license in assets/citationx.

The flight displays are simplified game instruments. Standby analog gauges, switches and auxiliary systems remain decorative. This is not a fully simulated Citation avionics system.

Validation: full gameplay regression, all ten aircraft completing land-stop-restart-takeoff-land-crash, stall/recovery, authored wreck preservation and localized deformation tests passed. Browser checks cover the selection/paint flow, cockpit display orientation, exterior and crash geometry. Physical iPad testing remains outstanding.

Remaining procedural aircraft: C-130 cargo plane and twin trainer.
