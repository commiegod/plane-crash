# Plane Crash / Impact Lab

A browser flight and aircraft-breakup sandbox. Choose a trainer, DC-10, or 747; fly a runway approach or trigger failures in flight.

## Play

Use GitHub Pages for this repository, or serve this directory with a local HTTP server. WebGL 2 is required. All runtime assets are included.

- Arrow keys / WASD: pitch and bank
- Q / E: throttle
- Space: engine cut / ground brakes
- G: landing gear
- C: camera
- P: pause
- R: reset

Landing Approach begins with assistance enabled. Failure Lab includes individual engine malfunction, engine fire, all-engine failure, fuel leak/exhaustion, hydraulic failure, gear jam, and a fictional onboard explosion. Repair & Refuel restores an intact aircraft for another experiment.

Models and physics are game approximations. See [asset credits](CREDITS.md) and [aircraft extension notes](AIRCRAFT-EXTENSIONS.md).
