# Boeing 727-230 — October 21, 2026

Adds the FlightGear community's GPLv2 Boeing 727-230 with original Lufthansa paint, modeled analog cockpit, three engines, source-based flap animations and landing gear. Crash sections retain the same geometry and textures. Source and conversion scripts are bundled in assets/b727/source.zip; attribution is in assets/b727/NOTICE.md.

Flight handling includes flap speed limits, loaded takeoff, assisted approach, go-around, stalls and repeat takeoff after landing. Performance and cockpit systems are simplified for the game; unconnected switches remain decorative.

Validation: B727 handling tests pass at 30/60/120 Hz on both runway ends. Fleet repeat-flight and stall checks pass for all eleven aircraft. Contact-safety, crash-settling and authored-wreck geometry checks pass. Browser checks confirmed the exterior, pilot view, twelve moving flap/slat nodes, fourteen responding instrument nodes, reversible animations, and textured three-section breakup. A shared animation fix resolves repeated cockpit instrument frames relative to their own parent.

Physical iPad testing has not been performed.
