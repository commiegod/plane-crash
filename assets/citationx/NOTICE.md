# Cessna Citation X model

Source: https://github.com/FGMEMBERS/CitationX
Revision: e497ad98591fa8d441eba188517b7238d6b1f85d

Aircraft by Syd Adams and FlightGear community contributors. Original instrument and model credits remain in the corresponding source files.

License: GNU General Public License version 2, as provided in the upstream COPYING file. See [license text](COPYING.txt) and [corresponding model source and conversion scripts](source.zip).

Adaptations: AC3D/XML converted to indexed glTF, compressed WebP textures, original black-stripe paint, pilot camera, gear visibility and matching textured crash geometry. Five screens show simplified live attitude, speed, altitude, heading, engine and fuel indications. Standby gauges, switches and auxiliary systems are decorative; this is not a complete Primus avionics simulation. No manufacturer endorsement is implied.
