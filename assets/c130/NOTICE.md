# Lockheed C-130 Hercules

Source: https://github.com/FGMEMBERS/C130
Revision: bbacb7a22c59932e19f4074e4b21232a0f53e727

Aircraft geometry by Emmanuel Baranger (Helijah), textures by Didier Fabert, with FlightGear community instrument contributions. Original credits remain in the source files.

License: GNU GPL version 2, as supplied upstream. [License](COPYING.txt); [corresponding source and conversion scripts](source.zip).

Adaptations: indexed glTF conversion, compressed WebP textures, original French-marked paint, four independent animated propellers, gear visibility, pilot camera, live analog flight/RPM instruments and matching authored wreckage. Unimplemented instrument covers are blanked. Auxiliary switches, radio and navigation systems remain decorative; flight/RPM readings are simplified game values. This classic four-blade Hercules replaces the procedural C-130J selection. No author or manufacturer endorsement is implied.
